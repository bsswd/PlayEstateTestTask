# PlayEstateTestTask


За всю логику работы приложения отвечает класс SceneManager. (Паттерн Singleton + фасад).
На старте он вызывает асинхронный загрузчик json-файла из класса JsonLoader.
Вся логика загрузки и валидации данных находится в классе JsonLoader. Путь - Content/Data.
Json парсится в структуру ApartmentConfigTypes.

Хотя в тестовом задании это и не предусматривалось - я реализовал спавнер для объектов 
в 3D мире. То есть можно в json написать здание любой этажности и разместить квартиры по 
координатам, спавнер автоматически создаст на старте приложения.

В качестве шаблона для генерации квартир используется класс ApartmentActor. Для простоты
визуализации - куб и динамический материал для интерактивности - ховер, подсветка выбранных 
квартир и для показа проданных.

Класс CameraPawn хранит в себе режим камеры (генплан, этаж, квартира) и простую логику управления
с клавиатуры, для простоты. (Но идеально конечно было бы перенести в PlayerController).
Переходы камеры реализованы в Tick для плавности. Математика и расчеты сделаны в отдельных методах.
Просмотр квартиры реализован с использованием LookAt.

SceneManager также вызывает логику работы UI. Существует главный виджет MainWidget, в котором
находится панель этажей, которая генерируется по данным из json-файла. Карточка с данными квартиры,
также заполняется из структуры. Также я написал универсальный класс кнопки, которая меняет свое
поведение в зависимости от контекста.
